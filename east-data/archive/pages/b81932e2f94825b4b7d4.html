Japanese translation of *Upādāyaprajñaptiprakaraṇa

Ui Hakuju. 1958. Jinna chosaku no kenkyū [*A study of Dignāga’s works]. Tōkyō: Iwanami Shōten.

Relations of Ui 1958 to works in EAST

  1. Ui 1958 is a modern translation of the *Upādāyaprajñaptiprakaraṇa.
  2. Ui 1958 is a modern translation of the Ālambanaparīkṣā.
  3. Ui 1958 is a modern translation of the Ālambanaparīkṣāvṛtti.
  4. Ui 1958 is a partial modern translation of the Commentary on Ālambanaparīkṣā and -vṛtti.
