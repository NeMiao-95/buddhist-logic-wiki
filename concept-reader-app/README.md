# ConceptPlug Reader — 插头式 AI 伴读与可复刻图谱编译器

这是一个纯静态前端 Web 应用（Local-First），既可在本地运行，也可直接部署为公开网站（GitHub Pages / Cloudflare Pages / Vercel），在不同电脑上获得一致体验。

## 核心功能

1. **概念节点与 7 个标准插头**：支持创建「圆圈」或「方格」概念节点，四周伸出 7 个插头（`P1 归属`、`P2 关联`、`P3 派生`、`P4 词义`、`P5 为何学`、`P6 创始者/典籍`、`P7 核心命题`），可在设置中自定义名称以匹配个人笔记体系。
2. **磁吸连接物理动画**：在连接型/混合型插头中输入内容时，自动做去 IAST 变音符、别名及模糊匹配检测；命中库中已有概念（如 `印度哲学的学派`）时，触发磁吸脉冲与弹簧牵引动画，将当前模块迅速吸向目标概念并连线。
3. **伴读资料库与极简短问答**：左侧可导入 `.txt` / `.md` 或粘贴正在阅读的书籍与补充资料（支持 `[p.12]` 页码标记），点开任意插头向 AI 提问，严格返回 80 字以内简短解释与原文出处锚点。
4. **封闭世界“图谱 → 说明文”编译器**：只打包当前节点事实 `[F*]`、关系边 `[E*]` 与一跳邻接概念 `[N*]`，按固定六段式骨架生成说明文，并通过正则审计校验器检测是否存在外部脑补或无来源断言；点击文中角标可反向定位画布插头与原书摘录。
5. **跨电脑同步**：支持整库导出/导入 `.json` 快照与导出 `.md` 说明文；右上角可配置任意 OpenAI 兼容 API（仅保存在本地浏览器），未配置时默认使用内置“本地严谨摘录 + 确定性编译”模式即可完整体验。

## 本地运行与测试

```bash
npm install
npm run dev          # 启动本地开发服务器
npm run test:engine  # 运行核心引擎单元测试
npm run build        # 打包纯静态产物到 dist/
```

## 公开网站部署

本项目已在 `vite.config.ts` 中配置 `base: "./"`，直接将 `dist/` 目录发布至 **GitHub Pages**、**Cloudflare Pages** 或 **Vercel** 即可在任何电脑打开使用。
